O **código** é aberto sob a Apache License 2.0 (veja `LICENSE`).
A **marca** — nome, logotipo e identidade visual — é licenciada por este
documento, e as regras são diferentes.

**Titular:** Brenno — https://github.com/AnThophicous

> Não sou advogado e isto não é parecer jurídico. É a intenção do projeto,
> escrita de forma clara para quem for usar o código. Registro de marca no
> Brasil se faz no INPI, e é ele que dá força real ao que está aqui.

## Em uma frase

Faça o que quiser com o código. Só não ganhe dinheiro com a **cara** do Markee:
para uso comercial, troque toda a identidade.

## O que conta como "a marca Markee"

- o nome **Markee** e variações que se confundam com ele
  ("Markee Pro", "Markee+", "Marke", "Markkee", "Markee Brasil");
- o logotipo, o ícone do aplicativo e a tela de abertura;
- o identificador do pacote `com.markee.app` e o esquema de link `markee://`;
- a combinação de identidade visual que representa o app.

## Uso **não comercial**: pode manter a marca

Se você não está ganhando dinheiro com isso — projeto pessoal, trabalho de
faculdade, servidor para a sua turma, pesquisa, ONG — pode usar o nome e o
logotipo do Markee no seu fork, desde que:

- deixe claro que **não é oficial** ("fork não oficial do Markee");
- aponte para este repositório;
- não dê a entender que é mantido ou aprovado por mim.

## Uso **comercial**: troque tudo antes

Uso comercial é qualquer um que gere receita — venda do app, assinatura,
anúncios, uso dentro de um produto pago, serviço hospedado cobrado.

O código permite isso (a Apache 2.0 permite). A marca, não. Para ir comercial,
**remova toda a identidade do Markee**:

- [ ] nome do app, em todo lugar (`app.json`, telas, textos, loja);
- [ ] logotipo, ícone e tela de abertura;
- [ ] identificador do pacote (`com.markee.app` → o seu);
- [ ] esquema de link (`markee://` → o seu);
- [ ] cores e identidade visual, se forem reconhecíveis como as do Markee.

Feito isso, **pode**, e não precisa me pedir nada. Você mantém os avisos de
copyright do código original, como a Apache 2.0 exige (`NOTICE`), e segue a sua
vida.

## Lojas de aplicativos

Só o titular publica sob o nome **Markee**. Fork rebrandeado pode ser publicado
livremente, com o nome e a identidade de vocês.

## O que sempre pode, sem pedir

- dizer que o seu projeto é "baseado no Markee" ou "um fork do Markee" —
  citar a origem é referência, não uso de marca;
- falar do Markee em artigos, vídeos, aulas e comparações;
- contribuir de volta (contribuições entram sob a Apache 2.0).

## O limite honesto disto

Uma licença não impede nada sozinha: ela define o que é permitido, e o que se
faz quando alguém ignora é processar. Marca registrada no INPI e um repositório
público com data são o que dá base para isso. Nenhum arquivo neste projeto
substitui esses dois.

Para pedir autorização de uso da marca fora destas regras, abra uma issue.
